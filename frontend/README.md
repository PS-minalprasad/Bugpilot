This directory will contain the React + TypeScript + Vite frontend application.

## Planned Tech Stack
- React 18 + TypeScript
- Vite (build tool)
- Vanilla CSS (custom design system — no TailwindCSS)

- `TrendChart` — bugs opened/closed per sprint
- `RiskMatrix` — component risk heatmap
- `AgentTimeline` — live agent execution visualization
- `ReportViewer` — final analysis report renderer
